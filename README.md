# Кубик свиданий

Телеграм-бот: первый бросок выбирает свидание (6 вариантов), второй бросок выбирает формат (6 на каждое).

## Как работает в вашем личном чате

Бота нельзя добавить в личную переписку двух людей, поэтому он работает через inline-режим:
1. В вашем чате с Ланой пишешь `@ИмяБота` и пробел, выбираешь «Кубик свиданий».
2. В чате появляется сообщение с кнопкой «Кинуть кубик». Нажать может любой из вас.
3. Первый бросок показывает свидание, второй показывает формат.

Если написать боту в личку или добавить его в общую группу, он кидает настоящий анимированный кубик Telegram.

## Запуск

1. В @BotFather: `/newbot`, получить токен.
2. Там же: `/setinline` для бота, написать любой текст подсказки (например «Кинуть кубик»).
3. Установить и запустить:

```
pip install -r requirements.txt
BOT_TOKEN=123456:ABC... python bot.py
```

Тексты свиданий и форматов лежат в `content.py`, правь свободно. Главное, чтобы оставалось 6 свиданий и по 6 форматов в каждом.
